Content Maxima

Video production orchestration that uses HTML as its editor.

Performance expectation

10 to 15 minutes for a VO video  ·  20 to 25 minutes for a talking head video

Step 3

Set your working folder

Open a new chat in Claude Code, click the folder button beside Local, and choose the folder where the files should be saved.

That folder is the root. Every editable, material, render, and metadata file is created there, whatever folder the package lives in.

Do it first. The picker sits above the chat box at the start of a session and disappears the moment you send your first message.

How to prompt

Claude Code

Read the [absolute path]/content-maxima/skills/creative-video-production.md

Use this Style ref: https://www.tiktok.com/@brand/video/0000000000

  • Talking head
  • Use music library
  • Avatar description: A white American woman aged 25 wearing a casual outfit

The script: [paste the approved script here, verbatim]

SEND

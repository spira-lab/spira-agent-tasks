# Nova — Subagent Roster

Every subagent Nova can call to complete a task.

## How to use

- **How agents run:** Atlas runs in the background through Nova's launcher; every other agent runs as Nova's helper agent and replies once. Designers are Atlas's, never Nova's.

- **How to call** — the exact name or invocation Nova uses.
- **What it can do** — its scope of work.
- **What to supply** — everything it needs from Nova to start and continue the work without coming back with questions.

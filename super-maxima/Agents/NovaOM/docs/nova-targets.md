# Nova — Output targets

How many original videos each brand needs, so Iris's track sheet can show what is made against
what is still needed for the month. Written by Nova only when the user sets, changes, or removes a
target. Counts are original videos (organic + ad) logged for the brand.
A blank cell means no target of that kind.

A brand needs one of the three. The month's goal is the monthly target when there is one;
otherwise the daily target × the working days (Monday to Friday) in the month; otherwise the
weekly target × the working days ÷ 5, rounded up. Weeks run Monday to Friday (the user's rule,
2026-10-22); weekends are not counted as working days.

**Counts from:** when a brand has a start date, only videos made on or after it count, and the
month's goal covers only the days from that date to the month's end (e.g. 100 a week from
Oct 14 → 100 × the working days from Oct 14 ÷ 5, rounded up). Blank means the whole month.

# Cookiy Earn Text Agent — professions

Each Cookiy Earn Text Agent script is built around one profession from this list: the person
speaking, or the expert a team is looking for. Writers pick only from this list, and never one
used in the brand's last 30 scripts (see the angle rules in `docs/echo-working-memory.md`).
One profession per line, after "- ". The owner or the Cookiy team can add or remove lines;
Echo's tools read the list as it is.

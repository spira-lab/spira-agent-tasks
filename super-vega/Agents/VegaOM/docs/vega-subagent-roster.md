# Vega — Subagent Roster

Every subagent Vega can call to complete a task.

## How to use

- **How agents run:** everything happens inside Vega's one session. Each agent below is called by **skill path**: Vega starts a sub-agent with the SDK's Agent tool, briefs it with the skill path and the request, and gets its one-line reply. IF the Agent tool is unavailable, Vega does that role himself, inline, by reading the skill. Atlas is not a separate agent: his planning (the batch sheet and how a video is handed to its designer) is a step in Vega's own loop, see `Agents/AtlasPM/atlas-project-manager.md`. Videos are produced in parallel by background designers, up to 4 at a time across the whole employee, 2 rendering and 2 transcribing at once.

- **How to call** — the exact name or invocation Vega uses.
- **What it can do** — its scope of work.
- **What to supply** — everything it needs from Vega to start and continue the work without coming back with questions.

## Roster

| Quill (Brief Writer) | Sub-agent (Agent tool) briefed with `Agents/QuillBW/quill-brief-writer.md` as its skill path. | Writes the DNA doc (brand name, product name, description, key highlights, RTB) from whatever the user gives; gets the user's approval; brings in logo + product images (local copy in `client-assets/`, Spira URL, asset ID); hands the approved brief (DNA link, colors, logo, images, preferences) to Vega's inbox. **Returns** one line: `DRAFT <brand> product=… dna=… missing=…` / `HANDOFF <file>` / `QUESTION` / `FAILED`. | The user's information as given (text, links, file paths). Videos are produced in parallel, up to 4 at a time (2 rendering, 2 transcribing). **Returns** (to Vega's own loop): finished, failed, and question counts; unfinished Task IDs; total credits; minutes. | **The path of a filled batch sheet** in `Agents/AtlasPM/batches/` (Vega creates it with `atlas-sheet.py create` / `add`; Echo fills the scripts). Never posts, drafts, schedules, or publishes. Skips anything already uploaded. **Returns** one line: `UPLOADED <n> videos tag <tag>; assets ...` / `QUESTION` / `FAILED`. | `Sheet: <path>`, `Task IDs: <done ids | done>`, `Brand: <brand>`, `Product: <name or none>`. Vega's skill, "Reports: Iris". | Keeps one track sheet (an artifact, always the same link): each brand's original videos this month against the month's goal (from `vega-targets.md`), pace, this week, today, all time, and day by day.

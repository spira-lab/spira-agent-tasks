# SFX index

One effect per line, for choosing sound effects (creative-video-production section 1).
file | category | intensity (subtle, medium, strong) | length | what it is and when it is best used
Fetch with `python3 tools/fetch-resource.py sfx/<file> …`. Each plays at the level stored in its file.
